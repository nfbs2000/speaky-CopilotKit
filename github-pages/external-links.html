appendix rule

부록 유지 규칙

외부 링크는 단순 bookmark가 아니라 공개 산출물의 목록이다. 새 repository나 새 Pages 장을 추가할 때는 source, Pages URL, 검증 기준을 같이 적는다.

  1. 새로 만든 공개 Pages는 이 부록에 반드시 추가한다.
  2. 외부 target의 source repository URL을 남긴다.
  3. GitHub Pages 배포 URL을 남긴다.
  4. 페이지가 설명하는 범위와 설명하지 않는 범위를 구분한다.
  5. 완료 판정에 필요한 test/API/UI/readback evidence를 명시한다.
  6. Pages가 아직 활성화되지 않은 경우 배포 전제 조건을 숨기지 않는다.
