book → live SDK → evidence → replay

Book SDK 4장 실제 증거 체인

책 문장을 모델에게 다시 말하게 한 결과가 아니다. Python Claude Agent SDK를 claude-opus-5로 실제 순차 실행하고, raw message와 host timing을 저장한 뒤 공개 가능한 OTel 사건으로 투영했다. 같은 판정을 각 저장소의 시각 문법으로 재생한다.

95 source events SDK raw message와 host process 관찰을 포함한 검증 원전. credential·private prompt·비공개 추론 payload는 공개하지 않는다.
32 public events source event ID와 SHA-256 연결을 유지한 공개 projection. renderer가 판정을 바꿀 수 없다.
4 observed read-only overlap, mutating serialization, message stop 전 tool 시작, interrupt cancellation을 직접 관찰했다.
2 more evidence built-in·annotation 없는 도구 scheduling과 progress/persistence/large-result 경로는 추가 live run이 필요하다.
1 invalid attempt 네트워크 retry·timeout으로 tool 사건이 생기지 않은 시도는 반증이 아니라 무효 시도로 분리했다.
범위 판정 4장의 end-to-end 공개 증거 체인이다. 아직 43개 prompt와 다른 장이 남아 있으므로 전체 책 검증 완료가 아니다.
기준 문서와 재생 표면 Cookbook · 4장 실제 Python SDK 관찰 Book SDK · 227장면 공개 슬라이드 Agent Flow · 원인과 tool lifecycle Runtime City · OTel 시간축과 실행 구역 Pixel Agents · actor 상태 재생 Hypnagonia · Observation Ordeal
CopilotKit과의 경계 이번 trace는 CopilotKit이 수집한 실행이 아니다. Education Shell projector가 만든 검증된 공개 증거다. 향후 Mothership → AG-UI adapter에도 같은 원칙을 적용한다. native event 소유권·source ID·Missing 판정을 보존하고, HITL 응답은 native permission.reply로 되돌려야 한다.

appendix rule

부록 유지 규칙

외부 링크는 단순 bookmark가 아니라 공개 산출물의 목록이다. 새 repository나 새 Pages 장을 추가할 때는 source, Pages URL, 검증 기준을 같이 적는다.

  1. 새로 만든 공개 Pages는 이 부록에 반드시 추가한다.
  2. 외부 target의 source repository URL을 남긴다.
  3. GitHub Pages 배포 URL을 남긴다.
  4. 페이지가 설명하는 범위와 설명하지 않는 범위를 구분한다.
  5. 완료 판정에 필요한 test/API/UI/readback evidence를 명시한다.
  6. Pages가 아직 활성화되지 않은 경우 배포 전제 조건을 숨기지 않는다.
