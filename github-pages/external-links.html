appendix rule

부록 유지 규칙

외부 링크는 단순 bookmark가 아니라 Mothership 경계 문서의 일부다. 새 repository를 추가할 때는 source, Pages URL, ownership 규칙, 검증 기준을 같이 적는다.

  1. 외부 target의 source repository URL을 남긴다.
  2. GitHub Pages 배포 URL을 남긴다.
  3. Mothership이 무엇을 소유하고 target이 무엇을 소유하는지 구분한다.
  4. 완료 판정에 필요한 test/API/UI/readback evidence를 명시한다.
  5. Pages가 아직 활성화되지 않은 경우 배포 전제 조건을 숨기지 않는다.
